프로젝트

1원본과 분석 자료 준비

원본 영상·채팅 수집 → 음성 전사 → 싱크 비교 자료를 준비합니다.

기존 자료는 재사용합니다. 실패했다면 작업 기록을 확인한 뒤 같은 버튼으로 다시 시도할 수 있습니다.

영상과 채팅 싱크 확인

샘플을 재생해 대사와 채팅을 비교하세요. 시간 보정이 필요하면 입력하고, 직접 확인한 경우에만 체크하세요. 채팅 없이 진행하는 작업은 이 단계를 생략합니다.

자료 준비가 끝나면 비교용 영상과 채팅이 나타납니다.
